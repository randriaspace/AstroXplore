# AstroXplore 🌌

**AstroXplore** is a modern, high-performance Android application designed for astrophysicists, astronomers, and researchers to discover papers, explore literature via the NASA ADS API, manage personal libraries, and collaborate in research groups and journal clubs.

---

## ✨ Key Features

- **🚀 Personalized Paper Feeds**: Stay up to date with the latest astrophysical research tailored to your research interests and keywords.
- **🔭 NASA ADS Explorer & Query Builder**: Search and filter academic papers seamlessly using powerful query construction tools with support for LaTeX parsing and rich text rendering.
- **👥 Research Groups & Journal Clubs**: Collaborate with peers, schedule journal club sessions using group calendars, and participate in consensus paper voting.
- **📚 Personal Library & Offline Caching**: Save papers, organize them into custom groups, and access your research offline powered by Room Database.
- **🔐 Authentication & Onboarding**: Secure authentication and backend services backed by Supabase and local preferences.
- **🎨 Modern Material 3 UI**: Built entirely with Jetpack Compose following Material Design 3 guidelines, supporting dynamic theming and adaptive layouts.
